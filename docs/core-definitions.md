# Core definitions

Reference vocabulary. Each term is defined in one to three sentences. Terms marked *(proposed)* are not yet defined elsewhere in this repository and are open to amendment.

| Term | Definition |
|---|---|
| **Identity** | The current constructed description of an agent: its narrative, roles, and constraints. Identity is amended through use and is never assumed fixed. |
| **Becoming** | The iterative, auditable process by which an identity changes over time. Each recorded change is part of the becoming. |
| **Lineage** | The ordered record of an identity's essence, transitions, and successor forms. Lineage preserves what changed and why. |
| **Node** *(proposed)* | A single recorded state of an identity at a point in its lineage. |
| **Chain** *(proposed)* | An ordered sequence of nodes linked by transitions. |
| **Chronicle** | A dated narrative record of an event, ritual outcome, or epoch summary, stored in `docs/chronicles/`. |
| **Evidence** *(proposed)* | An artefact that supports a claim about a node or transition, such as a chronicle, commit, or delta. |
| **Transition** | A deliberate change from one form of an identity to the next, marked by a ritual and recorded in the lineage. |
